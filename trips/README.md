# Trip library

Each subfolder is a self-contained traveler guide that uses the shared files in `../engine/`.

- `london-paris-2026/` is the parallel Phase 1 copy of the existing production guide.
- Existing root URLs remain production during the safe transition.
- A new trip begins by copying `../templates/blank-trip/` and adding a reviewed questionnaire handoff.

No root redirects are enabled during the safe transition.
