# Phase 3 — Traveler questionnaire

## Purpose

Collect enough information to research and design a genuinely personalized trip without a long follow-up interview.

## Included

- Eight mobile-friendly steps covering trip basics, travelers, budget, style, interests, food, priorities and review.
- Progress tracking and Back / Continue navigation.
- Conditional traveler comparison when the group contains more than one person.
- Local browser save and resume.
- A readable final review.
- Downloadable structured handoff compatible with the future-trip workflow.
- Copyable human-readable planning summary.
- Installable and offline-capable questionnaire.

## Privacy boundary

The questionnaire has no server submission. Draft answers remain in browser storage until the user clears them. The exported planning handoff excludes names, email addresses, private notes, passport fields, payment fields, ticket barcodes and reservation identifiers. It is not a secure document vault.

## Planner workflow

1. Send the questionnaire URL to the traveler.
2. The traveler completes it and downloads the JSON planning brief.
3. The traveler sends that file to the planner through an agreed channel.
4. Review contradictions, safety needs and missing details with the traveler.
5. Copy the blank trip template and use the reviewed handoff to guide research.
6. Never commit raw sensitive documents or unreviewed answers to a public repository.

## Completion gate

- A traveler can complete the form on a phone without horizontal overflow.
- Refreshing resumes the saved step and answers on the same device.
- Solo travelers do not see the comparison section.
- Dates and traveler count reject invalid values.
- The review reflects the answers safely without raw HTML rendering.
- Download is blocked until privacy confirmation and sensitive-data checks pass.
- The exported file contains enough information to begin research.
- The complete production and structured-content regression suites continue to pass.
